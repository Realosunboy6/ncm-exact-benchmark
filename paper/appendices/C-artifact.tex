\section{Artifact manifest}\label{app:artifact}

All paths are relative to \texttt{experiments/bench/} in the project
repository.
The generator, solver code, instance manifests, result files and analysis
scripts are available at \url{https://github.com/Realosunboy6/ncm-exact-benchmark}. Instance
binaries are not stored there: they reach 1\,GB at $n=500$ and are exactly
reproducible from the seeded generator, so the manifests carry SHA-256 hashes
instead. An archived snapshot carrying a permanent identifier will be deposited
on acceptance.
