\section{Artifact manifest}\label{app:artifact}

The generator, the solvers, the analysis scripts and every result file behind
every table are available at
\url{https://github.com/Realosunboy6/ncm-exact-benchmark}. Paths below are
relative to the artifact root. An archived snapshot carrying a permanent
identifier will be deposited on acceptance.

Instance binaries are not stored in full, since they reach 1\,GB at $n=500$;
the manifests record a hash and four numerical invariants of every instance
in every set except the perturbed equity panel at $n=2105$ and the bulk-level
pilot. The generator is seeded and reproduces those instances up to rounding:
regenerated on the original machine, each $G$ differs from the original by at
most $10^{-17}$ in relative Frobenius norm and each $\Xs$ is bit-identical,
although the hashes, taken on exact bits, differ. The script
\texttt{code/check\_instances.py} compares a regenerated set with the recorded
invariants instead. On another LAPACK build the generator may receive a basis
for the degenerate kernel of $\Xs$ in a rotated form, which yields different
members of the same family; the check detects this, since a rotated basis
moves the invariants by 15 to 20 per cent. A 12-instance subset of the
original instances at $n=100$ (2\,MB) ships with the artifact.

\paragraph{Development notes.}
\texttt{docs/} keeps the session-by-session run notes behind this paper's
results, including the equity-export commands and the timing re-run
protocol. They are a working log, not a specification: where a note cites a
file that a later run superseded, the note says so rather than being edited
to match.

\paragraph{Data not redistributed.}
The Anymatrix \texttt{CORRINV} matrices carry their own terms and are obtained
from their own repository. The two equity panels are built from vendor price
data that may not be redistributed; the exporters, the selection rules and all
result files are included, the raw prices are not.

{\sloppy
\paragraph{Figure data.} The files \texttt{paper/figures/data/*.dat} behind
every figure are written by \texttt{code/make\_figure\_data.py} from the result
files above, and \texttt{reproduce.sh} regenerates them for comparison. The
file \texttt{evd\_vs\_eps.dat} applies the cost-to-target rule of
\texttt{analyze\_ranking.py} (accepted-only, reach and hold) on a half-decade
grid of $\varepsilon$; at the five decade targets it reproduces \cref{tab:fwd},
up to that table's rounding of half-integer medians. The data behind
\cref{fig:native,fig:perevd}, like \cref{tab:primitive,tab:perevd,tab:native},
come from the timing runs.\par}
